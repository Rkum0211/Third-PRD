# Third-PRD
 Student Academic and Fee Clearance Tracker

A comprehensive console-based application for tracking student academic progress and managing fee clearances within an educational institution. This system provides detailed record-keeping for student demographics, course enrollments, academic performance, fee transactions, and generates essential reports.

## Features

### Student Management
- **Registration**: Enroll new students with comprehensive details including ID, name, age, email, course, semester, and career goals.
- **Academic Tracking**: Record marks for five subjects, calculate totals and percentages, and generate letter grades.
- **Attendance Monitoring**: Track class attendance and determine eligibility based on minimum attendance requirements.
- **Fee Management**: Manage course and assignment fees, track payments, and calculate remaining balances.
- **Status Updates**: Update student statuses such as promotion, re-admission, or debarment.

### Fee Management
- **Course Fee Calculation**: Automated calculation of total course fees based on the selected course and semester.
- **Payment Processing**: Record various payment methods including cash, check, UPI, and bank transfer.
- **Financial Reporting**: Generate fee clearance certificates and track payment histories.

### Reporting & Analysis
- **Grade Analysis**: Determine letter grades (O, A+, A, B+, B, C, F) based on performance.
- **Eligibility Checks**: Automated checks for academic performance, attendance, and assignment completion.
- **Generated Reports**:
    - Student Details Report (paginated)
    - Course-wise Student Report
    - Pending Dues Report
    - Academic Performance Report
    - Fee Clearance Certificate
    - Pass/Fail Analysis Report

### System Utilities
- **Data Persistence**: All student data is saved to `student_data.txt` for future access.
- **Search Functionality**: Easily search for students by ID or name.
